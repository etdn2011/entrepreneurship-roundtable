# 期望值分析

## 一句话核心
不要因为"有可能赚钱"就去做——算清楚：做成的概率×赚多少 - 做不成的概率×亏多少，结果为正再做。

## 底层逻辑

### 期望值公式
```
期望值 = (成功概率 × 成功收益) - (失败概率 × 失败亏损)
```

- 期望值为正 → 长远看值得做
- 期望值为负 → 长远看必亏
- 期望值为零 → 白折腾，不如不做

### 为什么这个思维对创业者很重要
创业者最常犯的错误是"单一结果导向"——只幻想"做成了有多好"，不考虑"做不成会亏多少"。期望值思维强迫你同时考虑两边，避免被美好的想象冲昏头。

### 关键洞察
- **胜率不是全部**：一个胜率70%但亏一次就全赔光的生意，期望值可能是负的
- **控制亏损比提高胜率更重要**：把失败时的亏损控制住，比把成功概率从50%提到60%效果更好
- **大赚小赔**：允许自己失败很多次，但每次失败的成本都很低；而成功一次就能覆盖所有成本

## 操作步骤

### 第一步：估算成功概率
不要瞎猜，用类比和参考数据：类似项目成功率多少？你比别人强在哪？尽量客观。

### 第二步：估算成功收益
做成了能赚多少？最好有上下限——"乐观能赚XX，保守能赚XX"。

### 第三步：估算失败亏损
最坏情况会亏多少？不只是钱，还有时间、机会成本、团队信心。

### 第四步：代入公式
(成功概率×成功收益) - (失败概率×失败亏损) = 期望值

### 第五步：根据结果决策
- 正期望值 + 亏损在承受范围内 → 值得做
- 正期望值但亏损超过承受范围 → 想办法降低亏损再试
- 负期望值 → 别做，或者换个方案
- 期望值≈0 → 如果对能力有锻炼作用可做，否则跳过

## 什么情况下好用
- 评估要不要投入一个创业方向
- 面临多个选择不知道选哪个
- 需要判断一个风险投资值不值得

## 什么情况下别用 / 容易犯的错
- 概率估算不可靠时，结果也没参考价值——先做好调研再算
- 有些"失败"的损失无法量化（比如信心打击、团队解散）
- 期望值为正但等不起——时间成本也是成本
- 小样本下期望值不适用——你需要足够多的"试验次数"来兑现期望值

## 在圆桌中怎么聊这个角度

- **老齐**（方向判断）：帮创业者做决策框架——"别只看做成了多好，也算算失败了会亏多少。两个一起看，才是一个完整的决策"
- **方鸣**（验证方法）：帮创业者算账——"算过账吗：做成的概率×能赚多少 — 做不成的概率×会亏多少，结果是正的还是负的？"
- **沈锐**（落地执行）：教创业者控制试错成本——"做之前先想好：失败的最大损失是多少？这个损失你能不能接受？如果亏得起就做"
- **苏慎**（风险排查）：警惕"赌一把"心态——"你说大概率能成，但你有没有想过：万一不成会亏多少？把亏的也算进去再决定"
